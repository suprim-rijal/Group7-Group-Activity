Host: Wants to list properties, manage availability, and get paid to earn income.



Admin: Wants to moderate listings, process payments, and resolve disputes to keep the platform safe.

Task:5

Product Owner: Maximizes the product's value. They represent the users, decide what needs to be built, and prioritize the Product Backlog.



Scrum Master: Facilitates the process. They coach the team on Scrum, remove blockers, and ensure ceremonies happen. They do not tell the developers how to code.



Developers: Build the product. They decide how to implement the features, estimate effort, and execute the work.



Task:6

Sprint Goal: "Enable a guest to search for and view suitable accommodations."



Sprint Backlog: The first two MVP stories (Search \& View Details).



Reasoning: You cannot book a property if you cannot find it first. This delivers the most foundational, testable user value immediately while leaving complex features (like payments) for later.



Task:7

Story: As a guest, I need to search by location and dates, so that I can find available places.



* Design the search bar UI.
* Create the frontend location and date-picker components.
* Build the backend search API endpoint.
* Write the database query to fetch available properties.



The Difference: A user story describes the value delivered to the user

in plain language. A task is a specific technical

step the Developers must take to build that story.



Task:8

Sprint Planning: The team agrees on the Sprint Goal and pulls top-priority items from the Product Backlog into the Sprint Backlog.

Daily Scrum: A quick 15-minute daily sync for Developers to share progress, align on the day's plan, and flag blockers.

Sprint Review: The team demonstrates the working software (e.g., the search function) to stakeholders to gather feedback.



Task:9

Product Backlog: The master list of everything desired for the product (features, bugs, ideas). It is owned and ordered by the product owner and is constantly changing.



Sprint Backlog: A locked, short-term list of work the Developers commit to finishing in the current Sprint. It is owned strictly by the Developers.



Task:10

Expected: A steady downward slope reaching zero on the last day.

Not decreasing : The team is blocked, or the tasks were harder than estimated.

Finishing early: The team overestimated the complexity or didn't bring enough work into the Sprint.



Final Discussion:

Roles = People, Artifacts = Lists, Ceremonies = Meetings.
